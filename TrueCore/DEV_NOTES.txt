TrueCore Development Notes

Architecture:
Office GUI -> packet_processor -> intel bridge -> TrueCoreIntel pipeline
Dev GUI -> Packet Studio / Dev Tools -> export / validation helpers

Build:
Use `python -m TrueCore.dev.build`.
Portable runtime outputs live in `dist\\OFFICE` and `dist\\DEVELOPMENT`.
Release upload artifacts live in `release\\`.

Versioning:
`TrueCore/VERSION.txt` stores the production version track.
`TrueCore/DEV_VERSION.txt` stores the dev version track.
`version.json` and `version-dev.json` are the update manifests.

Rules:
Return full file replacements only.
